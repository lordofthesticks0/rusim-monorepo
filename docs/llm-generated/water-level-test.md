# Water level sensor test

`firmware/tests/water-level/` is a standalone Arduino Uno sketch that samples
the analog water level sensor output on A0 and prints the raw ADC reading to
serial every 500 ms. Uno readings are in the range 0–1023; the sketch does not
convert them to a physical water level.

Connect sensor signal to A0 and connect sensor ground to Uno GND. Power the
sensor according to its module specifications. Keep the analog output within
the Uno's allowed input voltage range.

Build and upload with PlatformIO environment `water-level`, then open the
serial monitor at 115200 baud:

```sh
pio run -e water-level -t upload
pio device monitor -e water-level
```
