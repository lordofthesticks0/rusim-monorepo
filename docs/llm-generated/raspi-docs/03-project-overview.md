# 3. Project overview — `water-control-system`

The core application is **`water-control-system`**: a Flask web UI backend (plain Flask, no SocketIO) that drives a bioreactor/water-bath rig.

## What it does

- Reads bath temperature (DS18B20 on the Arduino master) and 4-bottle telemetry (temp, pH, methane, CO2, pressure) forwarded by the master.
- Controls the heater (SSR), circulation pump and stirrer via the master over serial commands. (The retired sketch in `water_control_arduino/` drove an exhaust fan on D4 instead; the current firmware drives the stirrer there.)
- Maintains a target bottle core temperature of 39.0 °C (hysteresis 0.3) with a 41.0 °C hard bath ceiling.
- Logs telemetry to daily CSV files (toggle "REC" in the UI).
- Exports CSV logs to a mounted USB drive.
- Provides network info, timezone/time setting, and a remote Pi shutdown endpoint.

## Runtime

- Backend listens on `0.0.0.0:5000`, debug off.
- Three daemon threads: `serial_worker` (auto-reconnect on `/dev/ttyACM0|USB0|ACM1|USB1`), `polling_worker` (boot defaults, then `STATUS` every 1 s and CSV rows while logging), and `telemetry_worker` (CPU/RAM/temperature/disk/power cache every 4 s).
- Global telemetry cache merged from master status + slave bottle data.
- CSV logging toggled via the UI "REC" button; writes to `logs/YYYY-MM-DD.csv`.
- USB export expects a drive at `/media/usb` (none mounted at the 2026-10-20 re-inspection).
