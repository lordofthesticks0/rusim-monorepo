# 3. Project overview — `water-control-system`

The core application is **`water-control-system`**: a Flask web UI + SocketIO backend that drives a bioreactor/water-bath rig.

## What it does

- Reads bath temperature (DS18B20 on the Arduino master) and 4-bottle telemetry (temp, pH, methane, CO2, pressure) forwarded by the master.
- Controls the heater (SSR), circulation pump and exhaust fan via the master over serial commands.
- Maintains a target bottle core temperature of 39.0 °C (hysteresis 0.3) with a 39.8 °C bath ceiling, emergency fan at 45 °C.
- Logs telemetry to daily CSV files (toggle "REC" in the UI).
- Exports CSV logs to a mounted USB drive.
- Provides network info, timezone/time setting, and a remote Pi shutdown endpoint.

## Runtime

- Backend listens on `0.0.0.0:5000`, debug off.
- Two daemon threads: `serial_worker` (auto-reconnect on `/dev/ttyACM0|USB0|ACM1|USB1`) and `polling_worker` (sends `STATUS` every 1 s).
- Global telemetry cache merged from master status + slave bottle data.
- CSV logging toggled via the UI "REC" button; writes to `logs/YYYY-MM-DD.csv`.
- USB export expects a drive at `/media/usb` (none mounted at the 2026-10-20 re-inspection).
