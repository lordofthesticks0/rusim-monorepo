## Architecture at a glance

```
┌──────────────────────┐   USB serial 115200    ┌──────────────────────┐
│  Raspberry Pi 3      │ ─────────────────────► │  Arduino (master)    │
│  Flask :5000 (PM2)   │ ◄───────────────────── │  DS18B20 bath temp   │
│  Chromium kiosk      │   master_status JSON   │  pump/stirrer/heater │
│  CSV logs            │                        │  RS485 DE/RE (D8)    │
└──────────────────────┘                        └──────────┬───────────┘
                                                          │ RS485 @ 9600
                                                          ▼
                                               ┌──────────────────────┐
                                               │  Slave "Mega Pro"    │
                                               │  4 bottles: temp,    │
                                               │  pH, CH4, CO2, press │
                                               └──────────────────────┘
```

The Pi never talks to the slave directly; all slave telemetry is forwarded by the master as JSON lines, which the Pi's `serial_worker` merges into a global cache that the kiosk UI polls over HTTP (`GET /status`, once per second). There is no SocketIO: the backend is plain Flask.
