# 9. Network & services

## Network Architecture (LAN Primary + Reserved Log Hotspot)

- **Primary Internet / Control Interface (`eth0` — LAN)**:
  - `eth0` (`10.92.128.23/21`, gateway `10.92.128.1`) serves as the exclusive primary network and default route for the system.
  - `/get_ip` in [`web_control.py`](../../../legacy/pi/water-control-system/web_control.py) queries `eth0` directly via `get_lan_ip()` and reports the connection mode (`Ethernet (LAN) · Wi-Fi Reserved` or `Ethernet (LAN) · Hotspot Active`).
- **Reserved Wi-Fi Interface (`wlan0` — Log Download Hotspot Only)**:
  - `disable_wifi_client_and_stop_hotspot()` runs at Flask startup and whenever the hotspot modal is closed (`/hotspot/stop`).
  - All `802-11-wireless` NetworkManager profiles are configured with `connection.autoconnect no` and `ipv4.never-default yes` so `wlan0` never connects to external Wi-Fi as a client and never overrides `eth0`'s default route.
  - While idle, `wlan0` is disconnected and the Wi-Fi radio is turned off (`nmcli radio wifi off`).
  - When a user initiates a log download (`/hotspot/start`), `web_control.py` enables the Wi-Fi radio, starts the `invitro-hotspot` AP (`SSID: InVitro-Hotspot`) on `wlan0` with `ipv4.never-default yes`, and serves the CSV over `/m/<filename>`. Closing the modal (`/hotspot/stop`) tears down the AP and powers off the Wi-Fi radio again.
- DNS resolution works (probe `connectivitycheck.gstatic.com` used by captive portal).
- A `cloudflared-app1.service` is enabled and active (Cloudflare tunnel).
