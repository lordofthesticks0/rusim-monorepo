# 9. Network & services

## Network Architecture (LAN Primary)

- **Primary interface (`eth0` — LAN)**:
  - `eth0` (`10.92.128.23`, gateway `10.92.128.1`) is the primary network and default route. The prefix length is recorded inconsistently across these documents — `/21` in `01-hardware-and-os.md` and `README.md`, `/24` here — both written from the same 2026-10-19/20 inspection. Run `ip -4 addr show eth0` on the Pi to settle it.
  - `/get_ip` in [`web_control.py`](../../../legacy/pi/water-control-system/web_control.py) queries `eth0` via `get_lan_ip()` and reports `Ethernet (LAN) · Wi-Fi Reserved`.
- **Wi-Fi (`wlan0` — kept off)**:
  - `disable_wifi_client_and_stop_hotspot()` runs at Flask startup, disables autoconnect on every wireless profile, and turns the Wi-Fi radio off.
  - The hotspot flow was removed. Log downloads now use the port 7514 server over the LAN.
- DNS resolution works (probe `connectivitycheck.gstatic.com` used by captive portal).
- A `cloudflared-app1.service` is enabled and active (Cloudflare tunnel).
- The Flask app runs a bare CSV download server on `0.0.0.0:7514` for phones on the same LAN. It has no HTML UI and no authentication.

## Security note (see §10)

SSH password auth with a trivial password was enabled at inspection (since fixed:
password login is disabled and keys are used, per `AGENTS.md`), alongside
passwordless sudo, autologin, an unauthenticated `/command` SHUTDOWN endpoint,
and an unauthenticated CSV download server on port 7514.
