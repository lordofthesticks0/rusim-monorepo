# Display `IS_DEBUG` flag

`IS_DEBUG` is the compile-time gate for debug-only shortcuts in the
`display-v9` UI. It is intentionally general: future debug shortcuts should
branch on it rather than adding a new flag each time.

The hardcoded default is currently `1` so development builds get the
debug shortcuts without extra flags. Flip it back to `0` (or build with
`-DIS_DEBUG=0`) before a production flash.

## Definition

`firmware/display-v9/ui_config.h`:

```c
#ifndef IS_DEBUG
#define IS_DEBUG 1
#endif
```

Because it is guarded by `#ifndef`, a `-DIS_DEBUG=0` build flag overrides
the hardcoded default without editing the source.

## Disabling it

Uncomment or add the line in `[env:display-v9]` in `platformio.ini`:

```
; -DIS_DEBUG=0
```

`[env:display-sim]` inherits `display-v9` build flags, so the same
flag disables it in the simulator. For a one-off production build without
editing the file:

```bash
PLATFORMIO_BUILD_FLAGS="-DIS_DEBUG=0" pio run -e display-v9
```

Both states compile: `pio run -e display-v9` and `pio run -e display-sim`
were verified with the current default (`1`) and earlier with `0`.

## Current effects

| Flag | Behaviour |
|---|---|
| `1` (default) | `/setup` (the login screen) shows an extra `DEBUG: bypass login` button (`firmware/display-v9/screen_setup.cpp`). Tapping it runs the normal success path (`setup_close_success()`): sets `g.loggedIn`, stops the credential SoftAP, and routes to `/home` without waiting for the WT32 `RESULT=success`. The USB serial console also accepts `W32CMD <line>` (arbitrary link line) and prints it in the `help` text (`serial_cmd.cpp`). |
| `0` | No change. All debug UI and `W32CMD` compile out. |

The boot still starts at the login screen in both modes; the flag only
adds a way past it. Later `LOGINREQ` lines from the WT32 still route
back to `/setup`, where the button is available again.

## Rules for new uses

- Guard with `#if IS_DEBUG`, so release builds (`0`) contain none of the
  debug code.
- Keep debug widgets visibly marked (`DEBUG:` prefix, warning colour).
- Never enable in a production flash: the bypass skips portal
  authentication. Build production images with `-DIS_DEBUG=0` (or set the
  `ui_config.h` default back to `0`) and re-check `help` on the USB console.
