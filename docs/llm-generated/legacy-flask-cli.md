# Legacy Flask CLI (`legacy/pi/water-control-system/flask_cli.py`)

User-friendly command-line client for the water-control Flask server
(`web_control.py`). Stdlib only — no `requests` needed. Run on the Pi
or a laptop.

## 1. Usage

```bash
python3 legacy/pi/water-control-system/flask_cli.py --help
python3 legacy/pi/water-control-system/flask_cli.py help
```

Global option: `--base-url URL` (default `http://127.0.0.1:5000`).
On the Pi the default works. From a laptop:

```bash
python3 legacy/pi/water-control-system/flask_cli.py \
  --base-url http://10.92.128.23:5000 status
```

Every subcommand prints pretty JSON. HTTP errors print the server body.

## 2. Controls (`POST /control`)

| Command | Sends |
|---|---|
| `heater AUTO\|ON\|OFF` | `{"action":"heater","mode":...}` |
| `pump AUTO\|ON\|OFF` | `{"action":"pump","mode":...}` (both pumps) |
| `pump-in AUTO\|ON\|OFF` (alias `pump1`) | `{"action":"pump1","mode":...}` |
| `pump-out AUTO\|ON\|OFF` (alias `pump2`) | `{"action":"pump2","mode":...}` |
| `pwm PIN 0-255` | `{"action":"mosfet_pwm","pin":...,"pwm":...}` |
| `stirrer OFF\|ON\|PULSE\|TIMED [MIN SEC]` | `{"action":"stirrer",...}` |
| `temp-target TARGET HYST` | `{"action":"temp_target",...}` |
| `thresholds OUT DRY IN LEAK` | `{"action":"thresholds",...}` (trip-only, e.g. `400 460 550 200`) |
| `mode AUTO\|OFF` | `POST /set_mode` (system mode) |

## 3. Server (`POST` + `GET`)

| Command | Endpoint |
|---|---|
| `reset-packets` | `POST /reset_packets` |
| `toggle-logging` | `POST /toggle_logging` |
| `download-info FILE.csv` | `POST /download/info` |
| `export FILE DEST` | `POST /export` |
| `set-timezone TIMEZONE` | `POST /set_timezone` |
| `set-time "DATETIME"` | `POST /set_time` |
| `shutdown` (needs `--force`) | `POST /command {"command":"SHUTDOWN"}` |
| `status` | `GET /status` |
| `raw [LIMIT]` | `GET /raw?limit=...` (default 100, max 500) |
| `sys-stats` | `GET /sys_stats` |
| `files` | `GET /files` |
| `read-log FILE [LINES]` | `GET /read_log?filename=...&lines=...` |
| `get-drives` | `GET /get_drives` |
| `get-ip` | `GET /get_ip` |
| `get-timezones` | `GET /get_timezones` |
| `download FILE [OUT]` | `POST /m/<FILE>` form download (portal login) |

`shutdown` refuses without `--force` so it cannot be triggered by accident.
